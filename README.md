# migrainelog

Migraine Log: Headache Tracker for iPhone. One tap logs an attack with the time; details can wait until you feel better. Mark headache-free days, see a calendar shaded by pain, count headache days, migraine days, long attacks and medication days by type, and share a one-page report with your doctor or insurer. Works offline, and nothing leaves the phone. A personal log, not medical advice.

Expo SDK 57, React Native, TypeScript, expo-sqlite, RevenueCat, expo-print. See CLAUDE.md for how shipping works and NOTES.md for the change log.

```
npm install
npx tsc --noEmit
npm test
npx expo start --ios
```
